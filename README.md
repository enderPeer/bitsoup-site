# bitsoup lab

The built site: https://enderpeer.github.io/bitsoup-site/

Machine evolution without a fitness function, run as one large world on two home GPU rigs.

This repository holds the generated pages, the data behind every chart (`data/`) and the maps. It is rebuilt and
replaced as a whole while the tracker runs, so it has one commit and no history. The history is in the data files.
